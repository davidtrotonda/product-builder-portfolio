# Save Troton — Mobile Game Case Study

## Summary

Save Troton was a mobile game I built in 2020 with Unity as one of my first product, game development and growth experiments.

## Context

I created the game while learning how to build and promote mobile products. I used it to test app store promotion, organic distribution and paid ads.

## What I built

- Mobile game.
- App store listing.
- Promotional video for acquisition.
- Early user acquisition experiment.

## Growth experiment

The goal was not monetization. The goal was to learn how to publish, promote and grow a mobile app.

I tested:

- Organic app store promotion.
- Store positioning.
- Paid ads using a video creative.
- Cost-per-download measurement.

## Results

- Around 1,000 downloads without ads, using app store promotion and organic promotion.
- Around 1,500 additional downloads with paid ads.
- Cost per download was around 0.08 EUR with the ad video.
- No in-app purchases.
- No monetization system inside the game.
- Later removed from Google Play because I did not keep it updated.

- CPI can be improved with creative testing.
- App store promotion can generate early installs without a large budget.

## What I would improve today
