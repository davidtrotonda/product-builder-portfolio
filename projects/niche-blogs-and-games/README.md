# Niche Blogs and Early Games — SEO and Product Experiments

## Summary

This stage included WordPress blogs, AdSense monetization, SEO content and small mobile games. It was where I started learning how to build, publish and grow internet products.

## Context

In 2020, I created a WordPress blog and monetized it with AdSense. After that, I created more blogs about building videogames and growing them.

## What I built

- WordPress blogs.
- SEO content.
- AdSense monetization.
- Content around game development and app growth.
- Small mobile game experiments.

## Results

- Monetized blogs with AdSense.
- Small games reached around 1,000 to 2,000 downloads.

## Stack / skills

- WordPress.
- SEO.
- AdSense.
- Content strategy.
- Mobile game publishing.
- Early product distribution.

## Source code

The original codebase is not included in this repository. This case study focuses on the product, growth experiment, technical decisions and learnings.

## What I learned

- Distribution is a skill that can be learned by publishing small projects.
- SEO can turn writing into an acquisition channel.
- Small products are useful for learning fast.

## What I would improve today

- Track conversion paths more clearly.
- Build a stronger content-to-product funnel.
- Use analytics from the beginning.
