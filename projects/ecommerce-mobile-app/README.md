# Ecommerce Mobile App — The Secret Home Case Study

## Summary

I built a mobile ecommerce app for The Secret Home to create an app-based sales and retention channel.

![The Secret Home app listing](./assets/01-google-play-listing.jpeg)

## Context

While I was in Lanzadera with Smusix, The Secret Home needed a mobile app. The owner had wanted one for years and had previously received a quote of around 15,000 EUR.

I built the app as a practical product for the ecommerce business.

## Problem

The ecommerce needed a mobile-first channel to improve repeat purchases, retention and direct customer access outside the browser experience.

## What I built

- Mobile ecommerce app.
- App-based shopping experience.
- Product browsing flow.
- Retention-focused mobile channel.
- App store presence.

## My role

- Product planning.
- Mobile app development.
- Ecommerce UX decisions.
- Store publishing support.
- Coordination with the business.

## Stack / skills

- Mobile app development.
- Ecommerce UX.
- App store publishing.
- Product and retention strategy.

## Results

- Around 5,000 downloads in a few months.
- Helped create a recurring sales channel through the mobile app.

## Source code

The original codebase is not included in this repository. This case study focuses on the product, business use case and results.

## What I learned

- Existing ecommerce businesses can benefit from focused mobile apps when they already have repeat customers.
- App store presence can become another trust and acquisition surface for a brand.
- Retention features matter more than a simple copy of the website.

## What I would improve today

- Add stronger push notification segmentation.
- Connect app analytics more deeply with customer cohorts.
- Add clearer retention dashboards.
